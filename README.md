# MovieLoc

O MovieLoc é um sistema de locação de filmes. O projeto tem como objetivo
representar uma solução de software utilizando os conceitos de Programação
Orientada a Objetos (POO).

O sistema foi desenvolvido para organizar informações relacionadas a filmes,
clientes e locações.
